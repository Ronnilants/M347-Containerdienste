# A) Dockerfile I

## Dokumentiertes Dockerfile

Das folgende Dockerfile wurde analysiert und jede Zeile erklärt:

```dockerfile
FROM nginx
# Verwendet das offizielle nginx-Image als Basis.
# Alle folgenden Anweisungen bauen auf diesem Image auf.

COPY static-html-directory /var/www/html
# Kopiert den lokalen Ordner "static-html-directory" in den
# Container-Pfad /var/www/html, wo nginx HTML-Dateien erwartet.

EXPOSE 80
# Informiert Docker, dass der Container auf Port 80 lauscht (HTTP).
# Öffnet den Port aber nicht automatisch – das passiert erst bei docker run -p.
```

---

## Eigenes Dockerfile (kn02a)

Das nginx-Image speichert HTML-Dateien unter `/usr/share/nginx/html`.  
Mit `WORKDIR` wird dieses Verzeichnis als Arbeitsverzeichnis gesetzt,  
dadurch braucht `COPY` keinen absoluten Pfad mehr.

```dockerfile
FROM nginx

WORKDIR /usr/share/nginx/html

COPY helloworld.html .

EXPOSE 80
```

---

## Docker Build Befehl

```bash
docker build -t ronnilants/kn02:kn02a .
```

---

## Container starten & Image pushen

```bash
# Container starten
docker run -d -p 8080:80 --name kn02a ronnilants/kn02:kn02a

# Auf Docker Hub pushen
docker login
docker push ronnilants/kn02:kn02a
```

# B) Dockerfile II

## Datenbank (MariaDB)

### Dockerfile kn02b-db

Die Zugangsdaten werden direkt im Dockerfile mit `ENV` definiert,  
damit sie beim Containerstart automatisch gesetzt werden.

```dockerfile
FROM mariadb

ENV MYSQL_ROOT_PASSWORD=rootpassword
ENV MYSQL_DATABASE=mysql
ENV MYSQL_USER=admin
ENV MYSQL_PASSWORD=adminpassword

EXPOSE 3306
```

### Docker Build & Run Befehle

```bash
# Image bauen
docker build -t ronnilants/kn02:kn02b-db .

# Container starten (Port 3307, da 3306 bereits belegt war)
docker run -d -p 3307:3306 --name kn02b-db ronnilants/kn02:kn02b-db
```

### Verbindung testen

Da Telnet auf Windows nicht standardmässig verfügbar ist,  
wurde die Verbindung mit PowerShell getestet:

```bash
Test-NetConnection -ComputerName localhost -Port 3307
```

Erwartete Ausgabe:
```
TcpTestSucceeded : True
```

## Webseite (PHP/Apache)

### Dockerfile kn02b-web

Das PHP Apache Image wird verwendet. Die beiden PHP-Dateien werden  
ins richtige Verzeichnis kopiert und das `mysqli` Modul wird installiert.

```dockerfile
FROM php:8.0-apache

WORKDIR /var/www/html

COPY info.php .
COPY db.php .

RUN docker-php-ext-install mysqli

EXPOSE 80
```

### Docker Build & Run Befehle

```bash
# Image bauen
docker build -t ronnilants/kn02:kn02b-web .

# Container starten
docker run -d -p 8081:80 --name kn02b-web ronnilants/kn02:kn02b-web
```

---

## Angepasste PHP-Dateien

### info.php

```php
<?php
phpinfo();
?>
```

### db.php

Die IP-Adresse `172.17.0.3` wurde mit `docker inspect kn02b-db` ermittelt.

```php
<?php
$connection = mysqli_connect("172.17.0.3", "root", "rootpassword", "mysql");

if ($connection) {
    echo "<h1>Verbindung erfolgreich!</h1>";
} else {
    echo "<h1>Verbindung fehlgeschlagen: " . mysqli_connect_error() . "</h1>";
}
?>
```
