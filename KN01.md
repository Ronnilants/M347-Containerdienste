## Teil B – Docker CLI

### 1. Docker Version überprüfen

**Befehl:**
```bash
docker version
```

Dieser Befehl zeigt die aktuell installierte Version von Docker an.

---

### 2. Images auf Docker Hub suchen

**Befehle:**
```bash
docker search ubuntu
docker search nginx
```

Mit `docker search` kann man auf Docker Hub nach öffentlichen Images suchen.

---

### 3. Erklärung: `docker run -d -p 80:80 docker/getting-started`

| Parameter | Bedeutung |
|---|---|
| `docker run` | Erstellt und startet einen neuen Container |
| `-d` | Detached-Modus: Container läuft im Hintergrund |
| `-p 80:80` | Port-Mapping: Port 80 vom Computer wird auf Port 80 im Container weitergeleitet |
| `docker/getting-started` | Name des Images, das verwendet wird |

---

### 4. nginx mit pull, create und start

Hier zeige ich, dass `docker run` dasselbe macht wie drei einzelne Befehle nacheinander.

**Befehle:**
```bash
# Image herunterladen
docker pull nginx

# Container erstellen mit Port-Mapping
docker create -p 8081:80 --name mein-nginx nginx

# Container starten
docker start mein-nginx
```

Danach ist nginx erreichbar unter: http://localhost:8081

### 5. Ubuntu Container im Hintergrund (`docker run -d`)

**Befehl:**
```bash
docker run -d ubuntu
```

**Was passiert:**
Das Ubuntu-Image wird automatisch heruntergeladen, weil es noch nicht lokal vorhanden war. Der Container startet kurz, beendet sich aber sofort wieder von selbst. Das liegt daran, dass Ubuntu keinen dauerhaften Vordergrundprozess hat, der ihn am Laufen hält. Docker Container laufen nur so lange, wie ihr Hauptprozess aktiv ist. Mit `docker ps -a` sieht man den Container mit dem Status "Exited".

---

### 6. Ubuntu Container interaktiv (`docker run -it`)

**Befehl:**
```bash
docker run -it ubuntu
```

**Was passiert:**
Mit den Flags `-it` öffnet sich eine interaktive Terminal-Session direkt im Container. Man landet automatisch in einer Bash-Shell innerhalb des Ubuntu-Containers. Man kann ganz normale Linux-Befehle eingeben und ausführen. Der Container bleibt aktiv, solange die Shell offen ist. Sobald man `exit` eingibt, wird die Shell beendet und der Container stoppt sich selbst.

---

### 7. Shell in laufendem nginx Container öffnen

**Befehl:**
```bash
docker exec -it mein-nginx /bin/bash
```

Dann im Container:
```bash
service nginx status
```

Mit `docker exec` öffnet man eine Shell in einem Container, der bereits läuft. Das ist der Unterschied zu `docker run -it`, wo man den Container erst neu startet.

### 9. nginx Container stoppen

**Befehl:**
```bash
docker stop mein-nginx
```

---

### 10. Alle Container löschen

**Befehl:**
```bash
docker rm $(docker ps -aq)
```

Dieser Befehl löscht alle Container auf einmal. `docker ps -aq` gibt alle Container-IDs zurück, `docker rm` löscht sie.

---

### 11. Images löschen

**Befehle:**
```bash
docker rmi nginx ubuntu
```

Mit `docker rmi` (remove image) entfernt man Images von der lokalen Umgebung.

---

### Alle verwendeten Befehle – Übersicht

```bash
docker version
docker search ubuntu
docker search nginx
docker pull nginx
docker create -p 8081:80 --name mein-nginx nginx
docker start mein-nginx
docker run -d ubuntu
docker run -it ubuntu
docker exec -it mein-nginx /bin/bash
service nginx status
exit
docker ps -a
docker stop mein-nginx
docker rm $(docker ps -aq)
docker rmi nginx ubuntu
```

## Teil D – Privates Repository

### 1. nginx Image taggen

**Befehl:**
```bash
docker tag nginx:latest BENUTZERNAME/m347:nginx
```

**Erklärung:**
`docker tag` erstellt einen neuen Namen (Tag) für ein bereits vorhandenes Image. Das Image selbst wird dabei nicht kopiert, es bekommt nur einen zusätzlichen Alias. Ein **Tag** ist eine Bezeichnung für eine bestimmte Version oder Variante eines Images (z.B. `latest`, `nginx`, `v1.0`). So kann man im gleichen Repository verschiedene Images speichern.

---

### 2. nginx Image hochladen

**Befehl:**
```bash
docker push BENUTZERNAME/m347:nginx
```

**Erklärung:**
`docker push` lädt das lokal gespeicherte Image auf Docker Hub in mein Repository hoch. Danach ist das Image online verfügbar und man könnte es von einem anderen Computer herunterladen.

---

### 3. mariadb Image herunterladen und taggen

**Befehle:**
```bash
docker pull mariadb
docker tag mariadb:latest BENUTZERNAME/m347:mariadb
```

---

### 4. mariadb hochladen

**Befehl:**
```bash
docker push BENUTZERNAME/m347:mariadb
```

---

### Alle verwendeten Befehle – Übersicht

```bash
docker pull nginx
docker tag nginx:latest BENUTZERNAME/m347:nginx
docker push BENUTZERNAME/m347:nginx
docker pull mariadb
docker tag mariadb:latest BENUTZERNAME/m347:mariadb
docker push BENUTZERNAME/m347:mariadb
```
