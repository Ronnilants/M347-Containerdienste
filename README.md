# Lernjournal – Tag 1 | KN01 Docker Grundlagen

Heute habe ich Docker Desktop installiert und meinen ersten Container gestartet. Ich habe gelernt wie man mit dem Docker CLI arbeitet und die wichtigsten Befehle wie `docker pull`, `docker run`, `docker start`, `docker stop` und `docker rm` verwendet. Ich habe mit den Images **nginx** und **ubuntu** gearbeitet und den Unterschied zwischen einem Container der im Hintergrund läuft (`-d`) und einem interaktiven Container (`-it`) kennengelernt. Zum Schluss habe ich einen Account auf Docker Hub erstellt, ein privates Repository **m347** angelegt und die Images nginx und mariadb mit `docker tag` und `docker push` hochgeladen.
