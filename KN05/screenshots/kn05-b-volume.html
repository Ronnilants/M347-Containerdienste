KN05 – B) Named Volume: Zwei Container, ein gemeinsames Volume

Container 1 (kn05-vol1) schreibt:

docker exec kn05-vol1 bash -c "echo 'Nachricht von Container 1...' >> /mnt/shared/messages.txt"

Container 2 (kn05-vol2) schreibt:

docker exec kn05-vol2 bash -c "echo 'Nachricht von Container 2...' >> /mnt/shared/messages.txt"

Container 1 liest /mnt/shared/messages.txt:

Nachricht von Container 1 (kn05-vol1): Hallo!
Zeitstempel: 06/09/2026 09:37:00
Nachricht von Container 2 (kn05-vol2): Ich sehe den Inhalt!
Zeitstempel: 06/09/2026 09:37:01

Container 2 liest /mnt/shared/messages.txt:

Nachricht von Container 1 (kn05-vol1): Hallo!
Zeitstempel: 06/09/2026 09:37:00
Nachricht von Container 2 (kn05-vol2): Ich sehe den Inhalt!
Zeitstempel: 06/09/2026 09:37:01

✓ Beide Container sehen exakt denselben Inhalt im geteilten Volume kn05-shared-vol
