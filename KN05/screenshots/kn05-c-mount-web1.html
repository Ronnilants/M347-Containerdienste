KN05 – C) docker compose: mount im ersten Container (kn05-web1)

Befehl: docker exec kn05-web1 mount | grep /mnt/

tmpfs on /mnt/tmpfs type tmpfs (rw,nosuid,nodev,noexec,relatime)   ← tmpfs Mount
C:\ on /mnt/bind type 9p (rw,noatime,dirsync,aname=drvfs;path=C:\;...)   ← Bind Mount
/dev/sde on /mnt/named type ext4 (rw,relatime)   ← Named Volume
